###Automatic flush
spdlog by default let the the underlying libc to flush whenever it sees fit to achieve good performance.

Use the boolean argument ```auto_flush``` to indicate the flush to disk policy:

* ```false``` (default): let the underlying libc to flush whenever it sees fit - recommended for max performance at the cost of delayed writes to the disk and the risk of losing log entries on application crush.

* ```true```: spdlog will flush to disk on every log call - Recommended when losing log entries upon crush is not tolerable even at the cost of performance.


The following example sets the file logger to auto_flush by setting the last ```auto_flush``` argument to true:

```c++
auto my_logger = 
    spdlog::rotating_logger_st("my_logger", "filename", 1024*1024*10, 5, true);
```


###Manual flush
You can use the ```logger->flush()``` function to make a logger flush its contents. Underneath it will call the ```flush()``` function on each of the underlying sinks.


###Flush interval
Under asynch mode, spdlog supports setting flush interval in millis. If this param is set in the set_asynch_mode call, then the logger will flush every interval automatically.
