Sinks are the objects that actually write the log to their target. Each sink should be responsible for only single target (e.g file, console, db)

Each logger contains a vector of one or more```std::shared_ptr<sink>```. On each log call (if the log level is right) the logger will call the ```"sink(log_msg)"``` function on each of them.



spdlog's sinks have _mt (multi threaded) or _st (single threaded) suffixes to indicate the thread safety.
While single threaded sinks cannot be used from multiple threads simultaneously, they are faster because no locking is employed.


### Available sinks

***Note:*** It is the user's responsibility to create any log folder they need. Spdlog will not attempt to create any folders, only files.

***

**rotating_file_sink**  ([sinks/file_sinks.h](https://github.com/gabime/spdlog/tree/master/include/spdlog/sinks/file_sinks.h)):

When the max file size is reached, close the file, rename it, and create a new file. Both the max file size and the max number of files are configurable in the constructor.

Usage example: 
```c++
// create a thread safe sink which will keep its file size to a maximum of 6MB and a maximum of 3 rotated files.
auto file_logger = spd::rotating_logger_mt("file_logger", "logs/mylogfile", 1048576 * 5, 3);
```
or create the sink manually and pass it to the logger:
```
auto rotating = make_shared<spdlog::sinks::rotating_file_sink_mt> ("log_filename", "log", 1024*1024, 5, false);
auto file_logger = make_shared<spdlog::logger>("my_logger", rotating);
```

***
**daily_file_sink** ([sinks/file_sinks.h](https://github.com/gabime/spdlog/tree/master/include/spdlog/sinks/file_sinks.h)):

Create a new log file every day at the specified time, appending a timestamp to the filename.

Usage example:
```c++
auto daily_logger = spd::daily_logger_mt("daily_logger", "logs/daily", 14, 55);
```

will create a thread safe sink which will create a new log file each day on 14:55.

***
**simple_file_sink** ([sinks/file_sinks.h](https://github.com/gabime/spdlog/tree/master/include/spdlog/sinks/file_sinks.h)):

A simple file sink that just writes to the given log file with no restrictions.

Usage example:
```c++
auto logger = spdlog::basic_logger_mt("mylogger", "log.txt");
```
***
**stdout_sink/stderr_sink** ([sinks/stdout_sinks.h](https://github.com/gabime/spdlog/tree/master/include/spdlog/sinks/stdout_sinks.h)):

Write to standard output/error.

Usage example:
```c++
auto console = spdlog::stdout_logger_mt("console");
auto err_console = spdlog::stderr_logger_mt("console");
```

***

**stdout_sink/stderr_sink with colors**  ([sinks/ansicolor_sink.h](https://github.com/gabime/spdlog/tree/master/include/spdlog/sinks/ansicolor_sink.h) and [sinks/wincolor_sink.h](https://github.com/gabime/spdlog/tree/master/include/spdlog/sinks/wincolor_sink.h)):

Write to standard output/error with colors.


Usage example (using spdlog's factory):
```c++
auto console = spdlg::stdout_color_mt("console");
auto err_console = spdlog::color_logger_mt("console");
```
Or create the sinks directly:

Windows:
```c++
auto sink = std::make_shared<spdlog::sinks::wincolor_stdout_sink_mt>();
```

Linux:
```c++
auto sink = std::make_shared<spdlog::sinks::ansicolor_stdout_sink_mt>();
```

***
**ostream_sink** ([sinks/ostream_sink.h](https://github.com/gabime/spdlog/tree/master/include/spdlog/sinks/ostream_sink.h)):

Write to the given std::ostream

Usage example:
```c++
std::ostringstream oss;
auto ostream_sink = std::make_shared<spdlog::sinks::ostream_sink_mt> (oss);
auto logger = std::make_shared<spdlog::logger>("my_logger", ostream_sink);
```

***
**null_sink** ([sinks/null_sink.h](https://github.com/gabime/spdlog/tree/master/include/spdlog/sinks/null_sink.h)):

null sink that throws away its log - can be used debugging or as reference implementation.

Usage example:
```c++
#include "spdlog/sinks/null_sink.h"
...
auto null_sink = make_shared<spdlog::sinks::null_sink_st> ();
auto logger = make_shared<spdlog::logger>("null_logger", null_sink)
```

***
**syslog_sink** ([sinks/syslog_sink.h](https://github.com/gabime/spdlog/tree/master/include/spdlog/sinks/syslog_sink.h)):

POSIX syslog(3) sink which sends its log to syslog. This sink is __disabled__ by default. Please edit ['tweakme.h'](https://github.com/gabime/spdlog/blob/master/include/spdlog/tweakme.h) to enable it.


Usage example:

```c++
auto syslog_logger = spd::syslog_logger("syslog", "my_ident");
```

***
**dist_sink** ([sinks/dist_sink.h](https://github.com/gabime/spdlog/tree/master/include/spdlog/sinks/dist_sink.h)):

Distribute log messages to a list of other sinks.

Usage example:
```c++

auto dist_sink = make_shared<spdlog::sinks::dist_sink_st>();
auto sink1 = make_shared<spdlog::sinks::stdout_sink_st>();
auto sink2 = make_shared<spdlog::sinks::simple_file_sink_st>("mylog.log");

dist_sink->add_sink(sink1);
dist_sink->add_sink(sink2);

```

***

**Multiple sinks with color console**

The color sink is actually a wrapper around the stdout_console. The following shows how to implement it.

```c++
std::vector<spdlog::sink_ptr> sinks;
auto stdout_sink = spdlog::sinks::stdout_sink_mt::instance();
auto color_sink = std::make_shared<spdlog::sinks::ansicolor_sink>(stdout_sink);
sinks.push_back(color_sink);
// Add more sinks here, if needed.
auto combined_logger = std::make_shared<spdlog::logger>("main", begin(sinks), end(sinks));
spdlog::register_logger(combined_logger);
```

**msvc_sink** ([sinks/msvc_sink.h](https://github.com/gabime/spdlog/blob/200815892f7fa036b2ec77ba3545452ba24cf4b9/include/spdlog/sinks/msvc_sink.h)) and **windebug_sink** ([sinks/windebug_sink.h](https://github.com/gabime/spdlog/blob/200815892f7fa036b2ec77ba3545452ba24cf4b9/include/spdlog/sinks/windebug_sink.h)):

Windows debug sink (logging using OutputDebugStringA).

windebug_sink is a synonym for msvc_sink

Usage example:

```c++
auto sink = spd::msvc_sink();
auto logger = std::make_shared<spdlog::logger>("msvc_logger", sink);
```

### Implementing your own sink

To implement your own sink, you'll need to implement the simple [sink](https://github.com/gabime/spdlog/tree/master/include/spdlog/sinks/sink.h) interface with the ```void log(const details::log_msg& msg)``` and ```void flush()``` functions.


For example: 
```c++
#include "spdlog/spdlog.h"
#include "spdlog/sinks/sink.h"
namespace spd = spdlog;

class my_sink : public spd::sinks::sink
{
  void log(const spd::details::log_msg& msg) override
  {
    // Your code here. 
    // details::log_msg is a struct containing the log entry info like level, timestamp, thread id etc.
    // msg.formatted contains the formatted log.
    // msg.raw contains pre formatted log
    std::cout << msg.formatted.str();
  }

 void flush() 
 {
     std::cout << std::flush;
 }

};
...
```

If your sink needs to use locks for thread safety, you can inherit from [base_sink](https://github.com/gabime/spdlog/tree/master/include/spdlog/sinks/base_sink.h) which will do the locking for you on each log call.
In this case you will need to implement the protected "_sink_it" and _flush() functions.

For example: 
```c++
class my_threaded_sink : public base_sink < std::mutex >
{
...
protected:
    void _sink_it(const spd::details::log_msg& msg) override
    {
        //Your code here
    }

    void _flush() override 
    {
       //Your code here
    }
...
}
```
